# Your Romantic Website 💖

Just open **index.html** in any browser — no install, no internet required.

## To personalize it

1. **Photos** — put your pictures in `images/` and list the filenames in
   the `photos` array near the top of `script.js`. Six labeled placeholder
   photos are there now so you can see it working immediately; replace or
   add to them (20–40 works great, but any number is fine).
2. **Quotes** — edit the `quotes` array in `script.js`.
3. **Love letter** — edit the `letter` string in `script.js`.
4. **Music** — drop your song into `music/` as `music.mp3` (see the note
   in that folder). Optional — the site works fine without it, it just
   won't play music.

Everything else (fonts, colors, animations, transitions) is in
`style.css` if you want to tweak the look, and is commented throughout.

## What's inside
- 10 different photo transitions (fade, zoom, cinematic, bloom, slides,
  rotate, blur-to-focus, heart-wipe, flower-bloom) chosen at random.
- Floating hearts, sparkles, butterflies, falling petals, drifting water
  lilies, light rays and stars — running continuously in the background.
- A flower-garden finale, a clickable wax-sealed envelope, a handwritten
  love-letter reveal, and a final heart-filled "Forever & Always" screen.
- Fully responsive (desktop/tablet/phone) and respects reduced-motion
  accessibility settings.
